# Чек-лист КТ 5 — этапы 10 (эссенция) и 11 (Наполнение)

Одиночная игра, творческий или выживание с правами оператора. Перед началом — новый мир (или копия старого).
Для каждого пункта: ✅ — как ожидается, ❌ — что не так (по возможности скриншот и `run/logs/latest.log`).

## 0. Подготовка

```
/thaumcraft research @s all
/gamerule doDaylightCycle false
/time set day
```

Ключи аспектов для команд: aer, ignis, aqua, terra, ordo, perditio, vitium, vitreus, vinculum, praemunio, potentia,
permutatio, motus, tenebrae, instrumentum, cognitio, sensus, exanimis, desiderium, aversio, bestia.

Банка, уже заполненная эссенцией (250 — полная), — пример:
```
/give @s thaumcraft:warded_jar[thaumcraft:aspects=[{key:"aer",amount:250}]]
```
Вис-кристалл нужного аспекта:
```
/give @s thaumcraft:crystal_essence[thaumcraft:aspects=[{key:"aer",amount:1}]] 16
```
Основные предметы: `thaumcraft:caster_basic`, `thaumcraft:salis_mundus`, `thaumcraft:infusion_matrix`,
`thaumcraft:arcane_pedestal`, `thaumcraft:arcane_stone`, `thaumcraft:thaumometer`, `thaumcraft:goggles`, `thaumcraft:thaumonomicon`.

## Часть А. Этап 10 — эссенция

Предметы: `essentia_smeltery`, `thaumium_essentia_smeltery`, `void_metal_essentia_smeltery`, `alembic`, `auxiliary_slurry_pump`,
`auxiliary_venting_port`, `centrifuge`, `warded_jar`, `void_jar`, `brain_jar`, `everfull_urn`, `essentia_tube`, `essentia_valve`,
`filtered_essentia_tube`, `restricted_essentia_tube`, `directional_essentia_tube`, `essentia_buffer`, `essentia_input`, `essentia_output`,
`magic_mirror`, `essentia_mirror`, `hand_mirror`, `phial`, `label`, `essentia_resonator`, `alchemical_construct`, `crucible`, `mnemonic_matrix`.

**Банки, фиалы, ярлыки**
 1. Защищённая банка: фиал с эссенцией (ПКМ по банке) — эссенция вливается, внутри виден цветной столб; пустым фиалом — набирается 10.
 2. Ярлык на банку (ПКМ): на ярлыке символ аспекта, банка принимает только его.
   Shift + пустая рука по ярлыку — ярлык снимается.
 3. Сломать банку с эссенцией → предмет с эссенцией (подсказка с аспектом), поставить — эссенция на месте.
 4. Пустотная банка: лишняя сверх 250 эссенция пропадает, трубы её не переполняют.
 5. Мозг в банке собирает сферы опыта рядом; ПКМ — отдаёт опыт; при сломе опыт сохраняется в предмете (подсказка).
 6. Неиссякаемая урна: вода в ведро/бутылку; трубы других модов забирают воду; тигли рядом получают воду.
 7. Ярлык на банке и алембике освещается как блок (в тени темнее), рисунок не повёрнут.

**Трубы**
 8. Трубка соединяется с банками и устройствами; клапан (ПКМ — открыть/закрыть, видно рычажок); фильтр (ярлык на ПКМ);
   ограничитель; односторонняя (стрелка); буфер (у каждой стороны свой режим давления — перчатка по грани).
 9. Перчатка заклинателя: ПКМ по трубке — переключение соединения на грани, у односторонней/буфера — поворот/режим;
   трубки подсвечиваются, пока перчатка в руке.
10. Резонатор эссенции по трубке — в чате тип и количество эссенции, всасывание.

**Плавильни, алембики, центрифуга**
11. Плавильня: смотрит на игрока; экран — слоты предмета и топлива, пламя, ход переплавки, шкала эссенции; горит — свет и
    дым/огонь спереди.
12. Переплавка: предмет с аспектами уходит, шкала растёт; алембик сверху (и над насосом сбоку) наполняется, видно ярлыком/фиалом.
13. Таумиумная плавильня отдаёт в алембики быстрее; потери эссенции → Выброс (таумометр); с отводящим клапаном часть потерь —
    пар и шипение.
14. Насос и клапан ставятся только на бок плавильни (не на лицо). Воронка: снизу — топливо, с боков — переплавляемое.
15. Алембик: ярлык на боковую грань (фильтр), Shift + пустая рука по ярлыку — снять, по другой грани — вылить (Выброс).
    Фиал набирает 10, банка-предмет — всё (до 250). Трубка сбоку — патрубок. Компаратор — по заполненности.
16. Центрифуга: составной аспект из трубы снизу → один из компонентов наверх; крестовина вращается, звук насоса;
    сигнал красного камня — остановка.

**Переливатели**
17. Ставятся на грань (смотрят от неё), труба — сзади. Наполняющий раскладывает эссенцию из трубы по банкам перед собой
    (до 16 блоков, видимый поток эссенции), опустошающий отдаёт трубе нужный ей аспект из банок.

**Зеркала**
18. Магическое зеркало (из творческого): зеркалом-предметом щёлкнуть по поставленному несвязанному — копия со связью;
    поставить её — оба зеркала «открываются» (портал, стекло). Брошенный в зеркало предмет вылетает из парного (дымка).
    Воронка в зеркало — тоже. Снять зеркало — выпадает связанным (модель открытого), у парного стекло снова матовое.
    Без опоры зеркало отваливается.
19. Связь через измерения: одно зеркало в Незере, другое в обычном мире — предмет переносится.
20. Зеркало эссенции: банка у одного зеркала, устройство (наполняющий переливатель или руническая матрица) у другого —
    эссенция идёт через пару.
21. Ручное зеркало: щелчок по магическому зеркалу — «Связь установлена»; ПКМ — окно, положенный предмет уходит в зеркало
    (в т.ч. из другого измерения). Зеркало сломано — «Связь разорвана», звук.
22. **Вопрос по DECISIONS 90:** связанное зеркало эссенции, к которому обращается устройство, при выгруженной паре
    загружает её чанк на каждый запрос (как в оригинале). Заметны ли подтормаживания/«мигание» чанка? Оставляем как есть или
    ограничиваем (например, перенос только при загруженной паре)?

**Тауматориум и схемы**
23. Тауматориум: тигель, над ним две алхимические конструкции; солью мира по нижней — искры, через ~2,5 с обе превращаются
    (лицом к игроку). Нагрев под тиглем; в слот катализатор; стрелками выбрать рецепт, щелчок по результату — выбран (рамка),
    счётчик x/y с матрицами. Трубы к бокам (не к лицу) — эссенция всасывается, результат вылетает спереди или уходит в сундук
    перед ним; над лицом парит результат. Красный камень — стоп. Убрать тигель — распад.
24. Мнемоническая матрица ставится только на бок тауматориума (не на лицо), +2 рецепта; без тауматориума выпадает.
25. Книга, «Тауматориум»: страница «Мистическая конструкция» — объёмная схема (тигель и две конструкции), ингредиенты снизу,
    кнопка справа внизу — послойный показ; в списке рецептов значок — схема готового тауматориума.
26. Пока ждут превращения (искры после соли мира), блоки структуры нельзя сломать.

## Часть Б. Этап 11 — Наполнение

Предметы: `infusion_matrix`, `arcane_pedestal`, `ancient_pedestal`, `eldritch_pedestal`, `arcane_stone`, `ancient_stone`,
`eldritch_stone`, `infusion_speed_stone`, `infusion_cost_stone`, `caster_basic`, свечи (`white_candle` и т.д.), `salis_mundus`.

**Алтарь**
27. Перчатка заклинателя: рецепт на магическом верстаке (100 Вис, по кристаллу каждого первичного аспекта; книга, «Основы
    ауромантии»); модель в руке, в инвентаре и от третьего лица.
28. Постройка: магический пьедестал; над ним, на 2 блока выше, руническая матрица; по четырём углам вокруг пьедестала (диагонали)
    столбики по 2 магического камня (всего 8). Соль мира по матрице → искры, затем камни превращаются в колонны
    (нижние — колонны, верхние исчезают), колонны смотрят наружу. Звук, облачко.
29. Колонна: выделение/столкновение высотой 2 блока; сломать — выпадает 2 магического камня, алтарь распадается
    (матрица гаснет).
30. Древний и потусторонний алтари: то же с `ancient_stone` / `eldritch_stone` и своими пьедесталами — свои модели колонн.
31. Книга, «Наполнение»: страница-схема алтаря (3 вида), послойный показ.

**Матрица и пьедесталы**
32. Матрица до включения — 8 тёмных кубиков. ПКМ перчаткой по матрице алтаря → звук, кубики расходятся и начинают
    вращаться, появляется свечение. Без алтаря — ничего.
33. Пьедестал: ПКМ предметом — кладётся (1 шт.), предмет парит и вращается над пьедесталом; пустой рукой — забирается.

**Наполнение (рецепт кластера, самый дешёвый)**
34. Рецепт кластера вис-кристаллов Aer: на центральный пьедестал — кристалл Aer; на пьедесталы вокруг (ниже матрицы, до 8 блоков
    по горизонтали) — семена пшеницы и соль мира. Рядом — банки: aer 10, vitreus 10, vinculum 5.
    ПКМ перчаткой по включённой матрице → начало: звук, руны над центральным пьедесталом, ускоренное вращение кубиков.
35. Ход: эссенция летит из банок к матрице потоком частиц своего цвета; затем предметы с пьедесталов распадаются
    (крошки предметов летят к центру, облачко, пьедестал пустеет); в конце на центральном пьедестале — кластер Aer
    (блок-предмет), молния/искры, звук.
36. Нет эссенции — процесс стоит (руны продолжаются); долив банку — продолжается.
37. Убрать предмет с бокового пьедестала во время наполнения — процесс стоит, растёт нестабильность.
38. Нестабильность (рецепт с нестабильностью — кластер Выброса `vitium`, или несимметричная расстановка пьедесталов):
    случаются события — сброс предмета с пьедестала (облачко), Выброс в ауру (таумометр), молния по игроку,
    эффекты «Отравление скверной» и «Лихорадка Выброса» на игроке (значки эффектов, вид в инвентаре),
    взрыв без разрушения блоков, Искажение. Первый раз — сообщение «Мне стоит подробнее изучить нестабильность наполнения».
39. Симметрия: пьедесталы и свечи/черепа симметрично — события заметно реже, чем при несимметричных.
40. Камни скорости/экономии наполнения под колонной (на 1 блок ниже колонны): быстрее/дешевле.
41. Перезаход в мир (или выход в меню и обратно) во время наполнения — процесс продолжается с того же места;
    выгрузка чанка (улететь > 10 чанков и вернуться) — тоже; предметы не дублируются и не пропадают.

**Рецепты (по одному каждого вида)**
42. Мозг в банке: банка + мозг зомби, глаза паука ×2, ведро воды; cognitio 25, sensus 25, exanimis 25.
43. Магическое зеркало (зеркальное стекло + 3 золотых слитка + жемчуг Края; motus 25, tenebrae 25, permutatio 25),
    зеркало эссенции, ручное зеркало — получаются и работают (пункты 18–21).
44. Книга: страницы наполнения — центральный предмет, кольцо ингредиентов, аспекты с подсказками, нестабильность
    («Нестабильность: Ничтожная…»), результат; для зачарований — пример инструмента.

**Наполняющие зачарования** (центр — инструмент, ингредиенты — зачарованная книга + предмет; эссенция — по книге)
45. Рецепт: например «Дуга» — деревянный меч в центре; вокруг зачарованная книга и блок красного камня; potentia 40, aer 60.
    Результат: в подсказке строка «Дуга I»; повторно — «Дуга II» (дороже); неподходящий инструмент — рецепт не начинается.
46. «Дуга»: удар по зомби в толпе — ещё 1 (на II — 2) моба рядом получает половину урона и отлетает; белый росчерк от цели
    к мобу и от игрока к цели; звук ветра.
47. «Зондирование» (кирка): ПКМ по камню — тихий звук, кирка −5 прочности; через мгновение руды вокруг (радиус 8 на I)
    подсвечиваются вспышками своего цвета (железо — бежевый, уголь — чёрный, алмаз — голубой…), дальние позже.
48. «Проходчик» (топор/кирка): ломаете нижний блок дерева — пропадает самый дальний блок ствола, дроп у него;
    с Shift — обычная ломка. Для жилы руды — то же.
49. «Очистка» (кирка): железная руда иногда даёт самородный кластер железа вместо сырого железа (звук опыта);
    с шёлковым касанием — кластер вместо блока руды.
50. «Разрушитель»: ломается 3×3 в плоскости грани, по которой бьёте (пол — горизонтальная плоскость, стена — вертикальная);
    инструмент изнашивается за каждый блок; с Shift — один блок.
51. «Собиратель»: добыча с блоков и мобов летит к игроку (синие пузырьки за предметом); с Shift для блоков — обычно.
52. «Сборщик эссенции»: убитые мобы иногда роняют вис-кристаллы своих аспектов (с «Собирателем» — летят к игроку).
53. Предмет с несколькими наполняющими зачарованиями может получить свойство «Искажение» — строка в подсказке.
54. Руническая защита (доспех + соль мира + янтарь; praemunio/vitreus/potentia): в подсказке «Рунический щит: +1»;
    сам щит (поглощение урона) — этап 13, сейчас только заряд в подсказке.

**Редкоземельные элементы**
55. Ломка алмазной/изумрудной/янтарной/кварцевой руды киркой (без шёлкового касания) иногда даёт «Редкоземельные элементы»
    (шанс 5–7,5 %, проверять удобнее на десятках руд); с шёлковым касанием — никогда. Взрыв руды — тоже может дать.

**Тексты**
56. Исследования «Основы наполнения», «Наполнение», «Наполнение: древний/потусторонний камень», «Усиление наполнения»,
    «Наполняющие зачарования», «Руническая защита», «Стабилизатор» — на русском, разметка (страницы, картинка алтаря) на месте.

## Ограничения из-за ещё не перенесённых этапов

- **Этап 12 (перчатка полностью):** у перчатки нет фокусов, Вис, меню и клавиш — только щелчок по блокам (DECISIONS 92).
  Рецепты фокусов наполнением (focus_2/3) — с этапом 12.
- **Этап 13:** руническая защита — только заряд в подсказке, щит не поглощает урон; рунические безделушки, амулет Вис,
  стихийные инструменты, «Таумиумная крепость» и прочие рецепты наполнения предметов этапа 13 — отсутствуют.
  Алюментум (топливо) — этап 13.
- **Этап 14:** мехи (ускорение плавильни), жидкости в схемах книги, адская печь. Стабилизатор (блок) — описан в книге, блока нет.
- **Этапы 15–16:** флюксовая слизь не появляется — при событиях нестабильности вместо неё Выброс в ауру (DEVIATIONS 35).
  Скверна от Выброса — только аура.
- **Этап 18:** печати големов (наполнение) — нет.
- Черепа как стабилизаторы — ванильные черепа учитываются; свои черепа/головы мода — позже.
- КТ 4 (этапы 8–9: верстак, тигель) — пункты по-прежнему ждут проверки, если ещё не пройдены (PROGRESS.md).
