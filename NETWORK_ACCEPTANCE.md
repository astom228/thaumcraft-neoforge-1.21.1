# Сетевое подключение и совместная установка модов — 5 ноября 2026

Практический прогон завершён: выделенный сервер и два настоящих клиента одновременно
работали с одинаковым набором модов. Неожиданных отключений, ошибок кодирования/обработки
пакетов Thaumcraft и новых нативных крашей в этом прогоне не обнаружено.
Это ограниченный игровой прогон, а не гарантия отсутствия ошибок при любой нагрузке.

## Проверенный профиль

Minecraft1.21.1, NeoForge21.1.252, Thaumcraft6.1.BETA17 текущих исходников,
Curios9.5.1+1.21.1, TerraBlender1.21.1-4.1.0.8;
Create6.0.10+mc1.21.1, JEI19.64.0.455, MezzConfig0.6.10,
Botania456-20260912.043547-15 (snapshot), Patchouli1.21.1-92-NEOFORGE.
Flywheel и Ponder загружены с Create. SHA-512 пяти внешних JAR во всех трёх папках
совпали с закреплённым `tools/compat/manifest.json`.

Профили `build/kt-server`, `build/kt-client1`, `build/kt-client2`, адрес127.0.0.1:25567,
игроки KtOne/KtTwo, запуски сервера41/42. Использован dev-запуск `-PtcAcceptance`:
Thaumcraft загружен из собранных классов/ресурсов с наблюдателем состояния, внешние моды —
из JAR. Отдельный запуск упакованного production-JAR этим прогоном не утверждается.

| Исследования и Искажение | Книга открылась, страница «Типы знаний» открыта кликом, отправляющим PacketSyncResearchFlagsToServer; серверная выдача METALLURGY появилась у KtTwo; TEMP7 появился у KtOne |

| Совместные реестры | Create:wrench и Botania:lexica_botania выданы и синхронизированы; запуск и перечисленные игровые действия прошли с полным профилем |

Первый вход KtOne06:25:40, KtTwo06:26:19; повторные входы06:30:24/06:31:47;
после рестарта06:33:41/06:34:44. Наблюдение продолжалось примерно10 минут,
с указанными плановыми переподключениями, без утверждения о многочасовом непрерывном сеансе.

В логах есть предупреждения движения сразу после операторских телепортаций. Отключений
из-за них не было. Botania содержит некорректный путь README в книге Patchouli, который
Minecraft игнорирует, и ссылки на отсутствующие рецепты gardenofglass; они не прервали игру.
Ошибочные подготовительные команды с несуществующими ключами исследования/предмета
отклонены штатно; затем использованы реальные METALLURGY и lexica_botania.
Переключение окон выполнялось через прежний нейтральный FocusBridge: новых hs_err не создано.

## Доказательства и границы

`build/kt-evidence/network-*`: логи двух запусков сервера/обоих клиентов, SHA-512 профилей,
снимки общего верстака, Незера, исследований, Искажения, состояния до/после рестарта,
отчёт effects23/23. Снимки пишутся наблюдателем раз в секунду; при сверке использованы
установившиеся состояния. Обычные пользовательские миры не использовались.

Результат подтверждает совместную установку и игру именно с перечисленными версиями.
Другие сборки, WAN/маршрутизатор/VPN, искусственные потери пакетов, онлайн-аутентификация,
многочасовая нагрузка и большое число игроков здесь не проверялись. Полная КТ-СЕТЬ
не отмечается завершённой по всем возможным сценариям. Изменений production-кода не потребовалось.
