# Thaumcraft 6 → NeoForge 1.21.1

Личный порт Thaumcraft 6 (Minecraft 1.12.2) на NeoForge 1.21.1. Только для себя, без публикации.

**В начале каждой сессии прочитать:** `MASTER_PROMPT.md` (главная инструкция), `PORTING_PLAN.md`, `PROGRESS.md`.
По фразе «продолжай» — продолжить с места, указанного в `PROGRESS.md`.

## Исходники для справки

- Оригинал: `reference/Thaumcraft-1.12.2-6.1.BETA17.jar`
- Baubles (для справки): `reference/Baubles-1.12-1.5.2.jar`
- Декомпилированный код (Vineflower): `reference/src/thaumcraft`, `reference/src/baubles` — SRG-имена.
  Только для чтения — **не править**.
- **Основной справочник — `reference/src-mcp/`**: тот же код с MCP-именами (только `.java`).
  Ассеты оригинала — в `reference/src/thaumcraft/assets/thaumcraft`.
- Папка `reference/` в git не попадает (`.gitignore`).

## Правила

- Цель — перенести механику и графику **1:1**. Ничего не улучшать и не придумывать.
  Вынужденные отступления — в `DEVIATIONS.md`, самостоятельные решения — в `DECISIONS.md`.
- Текстуры, звуки и переводы брать из оригинала без изменений.
- Mod ID: `thaumcraft`. Java-пакет: `thaumcraft` (структура пакетов как в оригинале).
- ID блоков и предметов — по схеме `ID_MAPPING.md` (ванильный стиль, варианты metadata разделены).
- Java 21 в `gradle.properties` (`org.gradle.java.home`) не менять.
- Работать маленькими этапами; после каждого подшага — `gradlew build`, после регистраций — `scripts/check-server.sh`.
  `gradlew runClient` самому не запускать.
- Перед большими изменениями сначала показывать план.
- Общаться с пользователем по-русски.

## Принятые решения (кратко, подробно в DECISIONS.md)

- Baubles → **Curios API**; биомы → **TerraBlender** (обе — обязательные зависимости).
- Варианты metadata → отдельные ID; совместимость с мирами 1.12.2 не нужна.
- Аура считается на серверном тике, без отдельного потока.

## Русский язык

Мод должен быть полностью на русском:
- `ru_ru` переносить из оригинала (`assets/thaumcraft/lang/ru_ru.lang` → `ru_ru.json`), `en_us` — так же (`en_us.lang` → `en_us.json`);
  ключи переименовывать под формат 1.21 и новые ID, значения не менять; устаревшие ключи не переносить;
- если строки в русском файле нет или она не переведена (осталась английской), переводить её на русский
  по словарю `GLOSSARY_RU.md` (термины оригинального перевода: Таумономикон, эссенция, Вис, Выброс (Flux),
  Искажение (Warp), Скверна/заражение (Taint), Наполнение (Infusion) и т.д.), пополняя словарь;
- разметку Таумономикона (`<IMG>`, `<BR>`, `<LINE>`, `<PAGE>`, `<DIV>`), коды `§x`, `%s` и переносы строк переносить без изменений;
- все новые строки (появившиеся при порте) сразу добавлять и в `en_us.json`, и в `ru_ru.json`;
- живой русский в стиле оригинала, не дословный машинный перевод.
