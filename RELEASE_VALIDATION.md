`thaumcraft-6.1.BETA17-port.1-beta.1.jar`

## Сборка и содержимое

- Java21; удалён `org.gradle.java.home` с локальным Windows-путём.
- Два независимых клона не содержали `reference` и прежнего `build`.
  Окончательный клон собран командой `gradlew.bat --no-daemon --offline --no-build-cache build`:
  все6 задач выполнены, BUILD SUCCESSFUL. Offline использует ранее загруженные Maven/
  Gradle-зависимости; тест полностью пустого сетевого кеша не заявляется.
- Окончательный JAR из чистого клона **побайтово совпал** с рабочей сборкой (SHA-256 выше).
  Исходный коммит упаковки: `376002a`; следующие изменения — документация/скрипт упаковки.
- При сравнении обнаружены и устранены включение `.cache` генератора и различие CRLF/LF
  ресурсов. Упаковка нормализует текст в LF и не сохраняет временные метки файлов.
- `verifyReleaseJar` входит в `build`: проверены metadata/версия, лицензия/авторство,
  отсутствие классов приёмки и кэша. В JAR нет Minecraft/NeoForge/Curios/TerraBlender JAR.

## Обычный Minecraft и выделенный сервер

Установщик NeoForge21.1.252 скачан с официального Maven и установлен в отдельные
папки `build/release-runtime/launcher` и `server`. Запуск стандартный:
BootstrapLauncher, цели **forgeclient / forgeserver**, Java21, Minecraft1.21.1.
Клиент использует официальный version JSON и обычные библиотеки установленного профиля;
это не `gradlew runClient`, не `net.neoforged.devlaunch.Main` и не developer runtime.
Управление аккаунтом/GUI Microsoft Launcher не проверялось. Для локального стенда
использован ReleaseTest и сервер online-mode=false, привязанный к127.0.0.1:25568.

В `mods` клиента и сервера находились ровно:

1. Окончательный JAR с указанным SHA-256.
2. Curios9.5.1+1.21.1.
3. TerraBlender1.21.1-4.1.0.8.

JEI, Create, Botania, тестовые классы и исходники проекта в runtime не включены.
Classpath не содержит `build/classes` и `build/resources` проекта.

Подтверждено:

- Обычный сервер создал новый мир, загрузил мод и достиг Done.
- Клиент загрузил мод именно из `mods`, подключился и повторно вошёл в мир;
  окончательный JAR проверен после отдельного перезапуска обоих процессов.
- Русские карта и страница «Типы знаний» открылись без JEI. На окончательном JAR
  сохранённое дерево ROOT→BOLT→FIRE открылось после рестарта.
- Через настоящий GUI введено «Релиз beta1», кнопкой начато изготовление в выживании:
  опыт10→9, Potentia/Ignis8→7. При обновлении прогресса дерево сохранялось;
  сервер показал vis13, затем vis0 и готовый пакет сложности7 с правильным именем.
- Сервер штатно сохранил все измерения и остановился.

Первая подготовка аргументов клиента включала vanilla-JAR под неправильным именем
и получила конфликт двух Minecraft-модулей; имя исправлено согласно ignoreList профиля.
Неполный options.txt без version был принят за старый формат клавиш; после первого
запуска использован полный файл формата3955. Это ошибки подготовки стенда, а не
исправления Thaumcraft. У окончательного запуска этих ошибок нет.

## Одиночная игра

После остановки обычного сервера его тестовый мир скопирован в отдельный
`client/saves/ReleaseSingleplayer`. Через меню «Одиночная игра» обычный клиент
с тем же окончательным JAR загрузил мир на **встроенном сервере**.
Сохранились место игрока, опыт9, кристаллы7/7 и созданный фокус в манипуляторе;
GUI открылся и показал имя «Релиз beta1». После закрытия Minecraft журнал подтвердил
штатное сохранение всех измерений. Это загрузка копии нового тестового серверного
мира, а не создание ещё одного одиночного мира через мастер генерации.
