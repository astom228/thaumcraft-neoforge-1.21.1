# Этап 20 — проверка интеграции JEI

Статус: **реализовано, клиентом не проверено**. КТ 4–10 и КТ-СЕТЬ остаются открытыми.
Этап начат до КТ 10 по отдельной прямой просьбе пользователя.

## Подготовка

Из `C:\mods\thaumcraft-port`:

```powershell
.\scripts\prepare-kt10.ps1 -Profile Base
.\gradlew.bat runClient
```

Base уже установлен: JEI 19.64.0.455, MezzConfig 0.6.10, Create 6.0.10.
Интеграция требует клиентский JEI >=19.64.0.455 и <20; без JEI мод продолжает работать.
API подключён только для компиляции, полный JEI и его библиотеки в jar Thaumcraft не включены.
Не добавляйте второй экземпляр JEI через Gradle и `run/mods` одновременно.

На тестовом мире выбрать русский язык. Для просмотра всех предметов можно использовать творческий режим.
R над предметом — рецепты, U — использование (если клавиши JEI не переназначены).

## Категории

- [ ] Магический верстак: R над таумиевым инструментом/перчаткой или U над верстаком открывает нужную категорию.
      Форма, пустые клетки, количества результата и кристаллов соответствуют Таумономикону.
- [ ] Бесформенные рецепты имеют отдельную подпись. Вис отображается как базовая стоимость до скидок экипировки.
- [ ] Тигель: видны катализатор, результат, точные количества эссенции и исследование.
      Для postAspects после входа и `/reload` не остаются пустые/нулевые цены.
- [ ] Наполнение: видны центральный предмет, окружающие компоненты, результат, нестабильность и эссенция.
      Обычные результаты и изменения компонентов (мешочки/безделушки и т.п.) отображаются корректно.
- [ ] U над рунической матрицей и таумометром открывает полный список соответствующей категории.
- [ ] Аспекты предметов: U над предметом открывает состав **одного** предмета, не всей стопки.
      Проверить также повреждённый инструмент, кристаллы разных аспектов и наполненный фиал.
- [ ] Аспекты в JEI имеют исходные значки, название/описание и количество. Это самостоятельный ингредиент просмотра,
      не предмет-кристалл и не жидкость. R над аспектом показывает предметы с ним; U — рецепты, которым он нужен.
- [ ] Кристаллы Aer/Ignis и фиалы разных аспектов не смешиваются при поиске рецептов.

## Динамическое наполнение

- [ ] U над бронёй/безделушкой без рунической защиты показывает усиление 0→1.
      U над уже усиленным предметом показывает следующий заряд и его стоимость, а не цену 0→1.
- [ ] R над предметом с руническим зарядом показывает предыдущий уровень как вход; число янтаря отображается суммарно.
- [ ] U/R над предметом с наполняющим зачарованием учитывает текущий уровень и остальные наполняющие зачарования.
      Выше максимального уровня рецепт не предлагается.
- [ ] Сортировка/порядок зачарований не создаёт разные рецепты для одинакового набора.
- [ ] Превью показывает вероятность дополнительного Искажения отдельно. Многократное открытие рецепта не меняет
      предмет, его Искажение, знания, инвентарь или мир.
- [ ] Переименованный предмет и предмет с lore находятся; результат сохраняет соответствующие компоненты,
      если их сохраняет сам рецепт. Одинаковые варианты не дублируются только из-за имени или нулевого заряда.
- [ ] Сохранить в закладки JEI рецепт улучшенного предмета/страницу аспектов, выйти и вернуться:
      закладка восстанавливает вход и пересчитывает актуальную цену. Повторить после `/reload`.

## Интерфейс и совместимость

- [ ] Проверить русский и английский язык, масштаб GUI 2/3/авто, поиск, наведение и переходы между категориями.
      Числа не перекрываются, все ингредиенты помещаются, исследование читается в подсказке.
- [ ] Просмотр рецепта не открывает исследование и не выдаёт скан. Изготовление в мире сохраняет серверные требования.
- [ ] Автоперенос ингредиентов из JEI не заявлен: интеграция предназначена для просмотра рецептов и аспектов.
- [ ] Два игрока на выделенном сервере видят рецепты; просмотр одного не изменяет предметы/знания другого.
- [ ] Выйти из мира, открыть другой, затем вернуться: старые варианты/цены не остаются.
- [ ] При необходимости повторить в профиле Botania из КТ 10; это официальный экспериментальный snapshot.
- [ ] Закрыть процессы, выполнить `prepare-kt10.ps1 -Profile Off`, запустить клиент без JEI:
      Thaumcraft открывается и работает. После теста вернуть `-Profile Base`.

## Что уже проверено без клиента

Сборка, сервер с Base и без JEI, 371 рецепт без расхождений, ресурсы и переводы (1581 ключ в каждом языке).
Серверный тест: 41 обычное наполнение, все 7 наполняющих зачарований, рунические заряды 0–6;
обратный поиск, все уровни зачарований с дополнительным зачарованием, точные компоненты результатов,
сохранение входа/Искажения и отсутствие случайного исполнения при превью.

Это не проверяет запуск самого клиентского плагина JEI, его вёрстку, переходы, закладки и скорость построения каталога.
Для сбоя нужны пункт, шаги и `run/logs/latest.log` (для второго клиента — `run-client2/logs/latest.log`),
для графики — скриншот. В логе работающего клиента ожидается строка `JEI display snapshot` с размерами каталогов.
