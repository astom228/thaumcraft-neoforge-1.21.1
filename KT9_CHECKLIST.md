# Чек-лист КТ 9 (этап 18): големы, печати, турели, магический бур

Удобнее вдвоём (сетевая игра) — пункты с пометкой 👥.
Для каждого пункта: ✅ — как ожидается, ❌ — что не так (скриншот, `run/logs/latest.log`).

## 0. Подготовка

```
/thaumcraft research @s all
/gamemode creative
```
Все предметы этапа — в творческой вкладке Thaumcraft: «Колокольчик големанта», «Голем», «Чистая печать»
и 15 управляющих печатей, «Автоматический арбалет», «Улучшенный автоматический арбалет», «Магический бур»,
«Магические рельсы активатора», «Заводной разум», «Биотаумический разум».

## 1. Пресс големов (18.4а)

1. Сборка: на нижнем ярусе — котёл, наковальня, поршень (смотрит вверх), каменный стол; над котлом — железная решётка
   (схема — в Таумономиконе, «Заводной разум»). Соль мира по любой части → вспышка, вместо блоков — пресс и заполнители.
2. Пресс отрисован моделью, при работе двигается.
3. Щелчок по прессу или любому заполнителю открывает окно: выбор материала, головы, рук, ног, дополнения
   (кнопки-стрелки, подсказки при наведении), стоимость деталей, кнопка сборки.
4. Сборка: детали забираются у игрока, пресс тянет эссенцию Машины (Machina) по трубам (банка с Machina + труба к прессу),
   полоса прогресса; готовый «Голем» появляется в выходной ячейке пресса. Без нужных исследований или деталей
   кнопка не срабатывает.
5. Разрушение любой части возвращает исходные блоки (котёл, наковальню и т.д.).
6. 👥 Второй игрок открывает тот же пресс — видит тот же прогресс; два игрока не могут запустить две сборки сразу.

## 2. Голем (18.2–18.3)

1. «Голем» ставится щелчком по блоку. Видны выбранные детали (материал, голова, руки, ноги, дополнение),
   у дерева/железа/бронзы и т.д. — свои текстуры.
2. Голем ходит (летающий — летает, с ногами-паучьими — лазает по стенам), колёса/гусеницы крутятся.
3. Эмоции над головой (сердечки, ноты, «?»), если включены в настройках графики; повышение ранга — звук и частицы.
4. Голем с «дальнобойными» руками стреляет дротиками (дротик отрисован).
5. Голем без печатей стоит на месте или возвращается домой; «за мной» и «стой» — с колокольчика.
6. Голем — не заражается Скверной, не исчезает после перезахода в мир.

## 3. Колокольчик и печати (18.4б, 18.5)

1. Печать ставится на грань блока; с колокольчиком в руке видны все печати и их зоны (цветные рамки).
2. Щелчок колокольчиком по печати — окно настройки: вкладки (приоритет/цвет, зона, фильтр, свойства),
   кнопки редстоуна, замка, белого/чёрного списка, «±» размеров зоны. Изменения сохраняются после закрытия.
3. Shift + щелчок колокольчиком по печати — печать снимается (с треском) и выпадает предметом.
4. 👥 Чужую закрытую печать второй игрок открыть/изменить не может; печать члена своей команды — может.
5. Печати по одной (каждая — с подходящим големом):
   - сбор — голем подбирает предметы в зоне;
   - хранение — относит в сундук с печатью;
   - опустошение — вынимает предметы из сундука;
   - охрана — бьёт враждебных существ в зоне;
   - урожай — собирает спелые растения и пересаживает;
   - забой — убивает лишних животных (оставляет пару);
   - лесоруб — рубит деревья;
   - разрушение блоков — ломает блоки по фильтру;
   - использование — ставит/применяет несомый предмет;
   - снабжение и запас — голем держит заданное количество предмета в сундуке с печатью запаса.
6. Окно логистики: Shift + правый щелчок колокольчиком по блоку (нужно исследование). Видны предметы из сундуков
   с печатями снабжения игрока, поиск по названию, ползунок количества, заказ — голем привозит не больше, чем есть.

## 4. Турели (18.6а)

1. «Автоматический арбалет» ставится на землю, стрелы — в окно (правый щелчок). Стреляет во враждебных существ,
   модель поворачивается, видна натяжка.
2. Стоит на раздатчике со стрелами — сам перезаряжается.
3. «Улучшенный автоматический арбалет» (модель OBJ): окно с переключателями целей (животные, мобы, игроки, друзья).
   👥 Второго игрока не атакует, пока цель «игроки» выключена; игроков в творческом режиме не трогает никогда.
4. Турель (и бур) на «Магических рельсах активатора» выключается, пока на рельсы подан сигнал редстоуна.

## 5. Магический бур (18.6б)

1. «Магический бур» ставится лицом от игрока; в окне — ячейка кирки (подойдёт любая кирка), свойства:
   ширина, глубина, скорость, прочие (Очистка, Удача, Шёлковое касание).
2. С киркой — зелёный вращающийся луч из кристалла, сгусток света; копает по спирали вперёд; частицы копания летят к буру.
3. Добыча — в сундук рядом с буром (или на землю). Кирка изнашивается; сломанная — бур останавливается.
4. Рядом с чужим приватом (если стоит мод защиты территорий) — блоки не ломает.

## 6. Рецепты и исследования (18.7)

1. В Таумономиконе, раздел «Големантия»: все 29 записей открываются, страницы рецептов печатей
   (тигель — 12, наполнение — урожай, забой, разрушение), «Биотаумический разум», «Магический бур» (наполнение),
   магические рецепты арбалетов, «Чистой печати», рельсов; обычный рецепт колокольчика.
2. Тигель: «Чистая печать» + Желание 10 → «Управляющая печать: сбор» (и остальные по книге).
3. Стол исследований: пресс големов / матрица наполнения / фокусный манипулятор рядом — появляются карточки
   големантии / артефактики / ауромантии.
4. Сканирование своего голема или турели таумометром — открывается «f_golem».

## 7. Сеть (👥)

1. Второй игрок видит големов, их детали, несомые предметы, эмоции, турели и луч бура.
2. Печати первого игрока второй видит только с колокольчиком в руке; зоны — тоже.
3. Выход и вход первого игрока — големы, печати и турели на месте, работают дальше.
