# КТ 10 — финальная проверка этапа 19

Статус: **подготовлено, в игре не пройдено**. Minecraft 1.21.1, NeoForge 21.1.252, Java 21.
Автоматические проверки и границы аудита — в [STAGE19_AUDIT.md](STAGE19_AUDIT.md).
КТ 4–9 и КТ-СЕТЬ остаются открытыми: эта проверка не заменяет их.

## 1. Подготовка и запуск

Команды PowerShell выполняются из `C:\mods\thaumcraft-port`. Используйте отдельный тестовый мир.
Для первого прохода уже установлен профиль Base во всех трёх папках запуска.

```powershell
# Create + JEI и зависимость JEI; скачивание с проверкой SHA-512 при отсутствии в кеше
.\scripts\prepare-kt10.ps1 -Profile Base
# Запуск клиента — выполняет пользователь
.\gradlew.bat runClient
```

Выберите русский язык. Для просмотра предметов и схем в творческой части теста:

```text
/gamemode creative
/thaumcraft research @s all
```

Проверку обычного продвижения исследований ниже проводите **отдельным игроком без команды all**.
Сохраните лог после обнаружения ошибки, до следующего запуска: `run/logs/latest.log`.

## 2. Наборы совместимости

|---|---|---|
| Create | 6.0.10+mc1.21.1 | Base / Botania |
| JEI | 19.64.0.455 | Base / Botania |
| MezzConfig | 0.6.10 (beta, обязательная библиотека выбранного JEI) | Base / Botania |

Curios 9.5.1+1.21.1 и TerraBlender 1.21.1-4.1.0.8 уже подключены Gradle;
в папки dev-запуска их повторно класть не нужно. Flywheel/Ponder/Registrate вложены в Create.
Ссылки на точные публикации, каналы и SHA-512 сохранены в `tools/compat/manifest.json`.

Botania пока находится в разработке для 1.21+:
[официальный статус](https://botaniamod.net/changelog.html),
[официальный snapshot 456](https://maven.blamejared.com/vazkii/botania/botania-neoforge-1.21.1/456-SNAPSHOT/).
Новый 457-SNAPSHOT требует NeoForge >=21.1.262, поэтому он не включён.
Сторонние порты не используются; выбранный snapshot — экспериментальный тест, не стабильный релиз.

Переключать профиль **после закрытия клиентов и сервера**:

```powershell
# Отдельный мир для проверки с официальным snapshot Botania
.\scripts\prepare-kt10.ps1 -Profile Botania
# Вернуть Base
.\scripts\prepare-kt10.ps1 -Profile Base
# Убрать только пять управляемых файлов из папок запуска (кеш остаётся)
.\scripts\prepare-kt10.ps1 -Profile Off
```

Скрипт обслуживает `run/mods`, `run-server/mods`, `run-client2/mods`, не меняет build.gradle,
не перезаписывает изменённые файлы набора и не удаляет остальные моды. Не добавляйте вторые версии тех же модов.

## 3. Книга, переводы и графика

- [ ] Таумономикон открывается; разделы, поиск, подсказки и страницы на русском; нет сырых ключей перевода.
- [ ] Открываются рецепты простой алхимии postAspects, нитора разных цветов, ярлыков эссенции,
      магического камня/кирпича, уха-переключателя и тройного мясного угощения; ссылки не ведут на пустую страницу.
- [ ] Многоблочные схемы с жидкостями отображаются; смена слоя не оставляет жидкость перед скрытыми блоками.
- [ ] Латы на одержимом зомби используют свою текстуру; нет розово-чёрной текстуры.
- [ ] Разлом Выброса отображается с разных углов, в очках и без; нет ошибок загрузки шейдера.
- [ ] Проверены `disableShaders=false` и `true` в `run/config/thaumcraft-client.toml`
      (при необходимости перезапустить клиент). При отключении остаётся обычная текстура.
- [ ] F3+T не ломает книгу, модели, разлом и звуки; в логе нет новой ошибки шейдера/ресурсов.

Пометка незавершённости скрытой записи BASEELDRITCH соответствует отсутствующим текстам BETA17;
нового измерения Внешних земель в этом порте нет.

## 4. Предметы и звук

- [ ] Первородная жемчужина сканируется в разных состояниях; сканирование другого предмета не открывает её запись.
- [ ] Коллапсер причинности (`thaumcraft:causality_collapser`) бросается, виден красный след;
      близкий разлом схлопывается, дальний остаётся. В выживании предмет расходуется, в творческом режиме сохраняется.
- [ ] Губка Выброса (`thaumcraft:creative_flux_sponge`) показывает русские подсказки:
      обычное применение убирает Выброс порциями до 500, крадучись также удаляет близкие разломы.
- [ ] Включены звуки: слышны сканирование, работа устройств, поток эссенции, коллапсер и события разлома;
      нет ошибок отсутствующих звуков. Снизить общую громкость до 0 и вернуть — настройка соблюдается.

## 5. Сервер, два игрока и повторный вход

В трёх отдельных окнах PowerShell:

```powershell
.\gradlew.bat runServer
.\gradlew.bat runClient
.\gradlew.bat runClient2
```

Клиенты Player1 и Player2 подключаются к `localhost:25565`; в текущем `run-server/ops.json` оба уже операторы.
Для корректной остановки выполнить `/stop` оператором в игре (консоль Gradle может не передавать stdin серверу).
Серверный лог: `run-server/logs/latest.log`, второй клиент: `run-client2/logs/latest.log`.

- [ ] Игроки видят свои знания/Искажение; сканирование и продвижение одного не открывают исследования другому.
- [ ] Игрок без all: при отсутствующем требовании стадии предметы не исчезают;
      при выполнении всех условий списывается нужное количество, повторное нажатие не даёт лишнего продвижения.
- [ ] В логистике быстро набрать/стереть поиск, несколько раз обновить: остаётся последний текст, окно отвечает,
      количества обновляются после изменения содержимого контейнеров; заказ не дублирует реальные предметы.
- [ ] При незагруженном парном зеркале проверка эссенции не рвёт связь; после возвращения к парному зеркалу
      перенос снова работает. Фактический перенос может загружать цель — ранее принятое поведение.
- [ ] Оператор выполняет `/reload`: аспекты на клиенте и страницы рецептов остаются доступны,
      оба игрока могут продолжить работу с устройствами.
- [ ] Смена измерения, смерть/возрождение и переподключение сохраняют знания/Искажение;
      старые печати, поток эссенции и туман не появляются в другом мире.
- [ ] Выйти в главное меню, открыть другой тестовый мир, затем вернуться: нет старой ауры в HUD,
      чужих аспектов от предыдущего набора, старых частиц и зависшего тумана.

## 6. Create, JEI и Botania

- [ ] В Base видны предметы Create и панель JEI; обычные рецепты Thaumcraft доступны в JEI.
      Специальных категорий магического верстака/тигля/наполнения пока нет — это этап 20 после КТ 10.
- [ ] Воронка Create подаёт предметы в голодный сундук и извлекает их; сохранение/повторный вход не дублирует содержимое.
- [ ] Механическая помпа Create наполняет водой магическую купальню; количество воды сохраняется,
      купальня расходует воду/соль при работе. Соль подавать сбоку/снизу — верхняя сторона не открывает предметный вход.
- [ ] В профиле Botania на новом тестовом мире открывается Lexica Botania, видны цветы/блоки;
      книга Thaumcraft, разломы и частицы продолжают отображаться без конфликтов.
- [ ] В Botania-профиле повторить `/reload`, переподключение и проверку воронки/помпы.
      Специальное наполнение алтаря лепестков из бездонного кувшина пока отложено — не считать его работающим.
