# Идеи на потом

Не реализуются в рамках порта; вернуться после завершения основных этапов.

## 1. Thaumic Tinkerer

Порт аддона Thaumic Tinkerer (версия для 1.12.2) — после завершения основного порта Thaumcraft.

## 2. Свой аддон «Багровые рейды»

Отдельный мод поверх нашего Thaumcraft, только через его API. Делать после этапа 16 или после завершения порта.

- После определённого прогресса (исследование или уровень Искажения) Багровый культ находит базу игрока
  (точка возрождения / место, где игрок проводит больше всего времени) и устраивает рейд.
- Портал рядом с базой, волны культистов, мини-босс — Багровый претор, полоса рейда.
- Настройки: частота, число волн, ломка блоков, поведение на мирной сложности.
- В мультиплеере рейд идёт на базу, а не на каждого игрока отдельно.

**Требование к порту (этап 16):** сущности культа (культисты, претор, портал) должны быть доступны через API
(`thaumcraft.api`), чтобы аддон мог их создавать и управлять ими.
